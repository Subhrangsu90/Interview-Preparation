What is NgRx SignalStore?

The signalStore() is a composable, standalone-first state management API for Angular. It provides a native Signals experience with built-in immutability, computed derivations, and side-effect management.

export const BooksStore = signalStore(
  withState({ books: [], query: '' }),
  withComputed(({ books, query }) => ({
    filtered: computed(() => /* signal */)
  })),
  withMethods((store) => ({
    search(q) { patchState(store, { query: q }); }
  }))
);

withState() Granular Reactive State

Defines state slices that automatically become writable signals. Supports deep immutability through patchState().
calculate
withComputed() Derived Signals

Adds memoized signals computed from existing state. Only re-evaluates when dependencies change, maximizing rendering performance.

withMethods() State Actions & Async

Exposes functions to patch state and execute asynchronous workflows using promises or rxMethod streams.

withHooks() Lifecycle Awareness

Executes lifecycle actions when the store initializes (onInit) or when it is destroyed (onDestroy).
